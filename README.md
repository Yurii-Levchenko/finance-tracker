# my-finance — трекер витрат для двох (Оля й Марко)

Особистий фінансовий трекер на Beancount 3. Зібраний на занятті 7 Warsaw IT School 5.0 і розширений у ДЗ #3: тепер він веде облік двох людей з різних банків.

**Усі дані тут штучні** — виписки Олі й Марка з умови завдання. Справжніх виписок у цьому репозиторії немає й не буде.

## Перевірка однією командою

Потрібен [uv](https://docs.astral.sh/uv/). У папці репозиторію:

```bash
uv run python check.py
```

Команда заново імпортує обидві виписки з `data/`, запускає `bean-check` і друкує контрольні змінні витрати:

| Хто | Серпень 2026 | Вересень 2026 |
|---|--:|--:|
| Оля | 2 195,21 | 2 582,42 |
| Марко | 1 855,57 | 2 432,83 |

Якщо все збігається, остання стрічка — «Усе збігається ✓», код виходу 0.

## Що де лежить
- `data/statement.csv` — виписка Олі (CSV її банку), `data/marko-statement.csv` — виписка Марка (польський формат «Historia operacji»).
- `import.py` — сам визначає формат кожної виписки й генерує `transactions.beancount`; кожна операція отримує тег власника `#olya` або `#marko`.
- `rules.csv` — правила категорій (шаблон в описі → рахунок, фіксована чи ні).
- `main.beancount` — рахунки, стартові залишки, збережені запити.
- `check.py` — перевірка однією командою (див. вище).
- `report.py` → `report.html` — звіт; `app.py` — сторінка зі звітом і формами для ручних операцій.
- `CLAUDE.md`, `PRD.md`, `IMPLEMENTATION_PLAN.md`, `PROGRESS.md` — правила й історія проєкту.
